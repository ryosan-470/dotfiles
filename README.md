Managed by [chezmoi](https://www.chezmoi.io/). See [docs/chezmoi.md](./docs/chezmoi.md) (Japanese) for how to add or change settings.
The private layer contract is documented in [docs/private-repo.md](./docs/private-repo.md) (Japanese).

## How to setup

```console
sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply \
  --source ~/code/src/github.com/ryosan-470/dotfiles ryosan-470
```

`chezmoi init` asks for the URL of the private repository (personal and work settings that are not public).
Use the same URL on every machine. Leave it empty if you do not use the private layer.
If you use the private layer, run `gh auth login` before `chezmoi init`.

## Update the configuration

```console
dot update   # chezmoi update (git pull + apply)
dot diff     # chezmoi diff
dot private  # move to ~/.config/private
```

## Layers

Settings are applied in the following order (later wins).

| Layer | Location | Managed by |
|---|---|---|
| Common | this repository (`home/`) | public repo |
| Private | `~/.config/private/` | one private repo for personal and work settings (`privateRepo`), cloned via `.chezmoiexternal` |
| Machine local | `~/.local.zsh`, `~/.gitconfig.local`, `~/.tmux.local.conf`, `~/.claude/CLAUDE.local.md` | not managed |

The private repository is expected to have the following layout (all files are optional).
Never commit secrets: tokens, private keys and AWS access keys belong in 1Password, not in the repository.

```
zsh/*.zsh               # sourced by ~/.zshrc (file name order)
gitconfig               # included by ~/.gitconfig (use includeIf for work repositories)
tmux.conf               # sourced by ~/.tmux.conf
claude/CLAUDE.md        # imported by ~/.claude/CLAUDE.md
claude/settings.json    # merged into ~/.claude/settings.json
Brewfile                # installed by brew bundle (macOS)
aws/config              # symlinked to ~/.aws/config (600)
```

### Claude Code settings

Claude Code rewrites `~/.claude/settings.json` by itself, so it is generated by
`home/dot_claude/modify_settings.json.tmpl`, which merges the current file,
`home/dot_claude/settings.base.json` and the private layer.
Permissions are unioned; removing a permission from the base file does not remove it from existing machines.

## Dependencies

- zsh
  - [zimfw](https://github.com/zimfw/zimfw)
- tmux
  - [tmux plugin manager](https://github.com/tmux-plugins/tpm) (installed by chezmoi)
- jq (for merging Claude Code settings)
- [rtk](https://github.com/rtk-ai/rtk) (optional, referenced by the Claude Code hook and `@RTK.md` in `~/.claude/CLAUDE.md`)
  - `~/.claude/RTK.md` is generated by `rtk init -g` and is not managed by chezmoi. Without it, the `@RTK.md` import is simply ignored.

## Periodic cache cleanup (macOS)

`~/.local/bin/cleanup-caches.sh` cleans up regenerable development caches (go build cache, uv, Homebrew, pnpm, npm, mise, dangling docker images/build cache).
It runs on the 1st of every month at 12:00 via launchd. Logs are written to `~/Library/Logs/cleanup-caches.log`.

The LaunchAgent is deployed to `~/Library/LaunchAgents/` and (re)loaded by `chezmoi apply` automatically on macOS.

```bash
# Run it now
launchctl kickstart gui/$(id -u)/com.ryosan470.cleanup-caches

# Uninstall
launchctl bootout gui/$(id -u)/com.ryosan470.cleanup-caches
rm ~/Library/LaunchAgents/com.ryosan470.cleanup-caches.plist
```
